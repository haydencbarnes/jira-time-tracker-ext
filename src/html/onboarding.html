Getting started with Jira Log Time

Five short steps: connect your Jira account, then log time from the Time Table, the Timer, the floating timer, or your daily plan.

1

Connect your Jira account

Open Settings (the gear in the top-right corner of the popup, or right-click the toolbar icon and choose Options) and fill in the Account page.

  1. Jira instance: pick Jira Cloud for *.atlassian.net sites, or Jira Server for a self-hosted Server / Data Center instance.
  2. Jira URL: your site address, for example https://your-team.atlassian.net.
  3. Username or email: the email on your Atlassian account (Cloud) or your Jira username (Server).
  4. API token: on Cloud, create one at id.atlassian.com → Security → API tokens. On Server / Data Center, use a personal access token from your profile (or your password if tokens are disabled).
  5. Click Save next to each field you change. Settings are stored in your Chrome profile and sync with your Google account.
2

Log time from the Time Table

Click the extension icon in the toolbar. The Table tab lists your work items, with one row per issue.

  1. Rows come from a JQL query. The default shows issues assigned to you or that you have logged time on, excluding Closed and Done. Change it from the gear icon at the top right of the table.
  2. Type a duration in Log (1h 30m, 45m, 2h), add an optional worklog comment, and pick the date.
  3. Press the blue ⇡ button on the row to post the worklog. The Total column updates immediately.
  • ★ pins an issue to the top of the table. Hover the issue key to see its last five worklogs.
  • The 1 and 2 buttons insert your saved worklog snippets (Settings → Worklog snippets).
  • The gear also toggles the Status, Assignee, Total, and Comment columns, sets the sort order, and lets you drag columns into a new order.
  • Week and Stats show what you have already logged.
3

Track work with the Timer

Open the stopwatch icon in the footer, or make the Timer your default tab under Settings → Behavior.

  1. Pick a Project ID and a Work Item ID from the autocomplete lists, or type a key such as ACME-42 directly. The project follows the key you type.
  2. Press ▶ to start. The timer keeps running while the popup is closed, and the toolbar badge shows the elapsed time.
  3. Use ✎ to edit the elapsed time, 🗑 to reset, and 💬 to add a worklog comment.
  4. Press ⇡ to log the elapsed time to the work item. The timer resets after a successful log.
4

Keep the timer in view on any page

Turn on Floating timer under Settings → Behavior and a small pill follows you onto every web page.

  • It shows the current work item and elapsed time. Choose whether it displays the ID and title, the title only, or the ID only.
  • Drag it anywhere by the grip on the left; it remembers its spot.
  • ▶ / ⏸ starts and pauses, 🗑 resets, and ⇡ opens a confirmation showing exactly what will be logged. A green outline and a short chime confirm success.
  • Hover the grip for three seconds and it becomes an ✕. Clicking it hides the floating timer without stopping the timer; turn it back on in Settings.
5

Plan your day

The Plan tab lays out how you want to spend the day and lets you log each block when it is done.

  1. Set your Day capacity (for example 8h).
  2. Add work items from your Time Table and give each a planned duration. Drag the ☰ handle to reorder.
  3. Press Log on a row. A dialog shows the issue, the date, and the time that will be posted; confirm to log it.
  4. Use the arrows next to the date to plan tomorrow or review earlier days.
✓

More ways to save time

  • Work item detection Issue keys on any web page get a small timer icon. Click it to log time without leaving the page (Settings → Behavior).
  • Search The magnifier in the footer finds any issue, even ones outside your JQL, and logs time to it.
  • CLI The » page takes one-line commands like ACME-42 1h 30m yesterday Fix tests.
  • Worklog snippets Save two comment presets under Settings → Worklog snippets and insert them with the 1 and 2 buttons.
  • Dark mode Use the 🌙 button in the footer, or follow your system theme from Settings → Behavior.
  • Full-page view Under Settings → Experimental, open the extension in a tab instead of a popup.
